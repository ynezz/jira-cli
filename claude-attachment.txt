     Implementation Steps

     Phase 1: API Layer

     1.1 Add types to pkg/jira/types.go

     // Attachment holds attachment metadata
     type Attachment struct {
         ID       string `json:"id"`
         Filename string `json:"filename"`
         Author   User   `json:"author"`
         Created  string `json:"created"`
         Size     int64  `json:"size"`
         MimeType string `json:"mimeType"`
         Content  string `json:"content"`  // Download URL
     }

     Add to IssueFields struct:
     Attachment []Attachment `json:"attachment"`

     1.2 Create pkg/jira/attachment.go

     Methods to implement:
     Method: AddAttachment(key, filePath string)
     Jira API: POST /issue/{key}/attachments
     Notes: Multipart form-data, X-Atlassian-Token: no-check header
     ────────────────────────────────────────
     Method: GetAttachments(key string)
     Jira API: GET /issue/{key}?fields=attachment
     Notes: Extract from issue fields
     ────────────────────────────────────────
     Method: DownloadAttachment(id, destPath string)
     Jira API: GET /attachment/content/{id}
     Notes: Stream to file
     ────────────────────────────────────────
     Method: DeleteAttachment(id string)
     Jira API: DELETE /attachment/{id}
     Notes: Returns 204
     1.3 Add multipart support to pkg/jira/client.go

     Add method for multipart/form-data POST requests (required for file
     uploads).

     Phase 2: View Layer

     2.1 Create internal/view/attachment.go

     Table columns: ID, FILENAME, SIZE, AUTHOR, CREATED, MIMETYPE

     Follow pattern from internal/view/sprint.go.

     Phase 3: Commands

     3.1 Parent command internal/cmd/issue/attachment/attachment.go

     jira issue attachment [command]

     Commands:
       add       Add attachment(s) to an issue
       list      List attachments on an issue
       download  Download attachment(s) from an issue
       remove    Remove an attachment

     Aliases: attachments, att

     3.2 Add command

     jira issue attachment add ISSUE-KEY --file path/to/file [--file
     another/file]

     Flags:
     - --file, -f (required, repeatable) - File path(s) to upload

     3.3 List command

     jira issue attachment list ISSUE-KEY [--plain] [--no-headers]

     Flags:
     - --plain - Plain text output
     - --no-headers - Skip column headers

     3.4 Download command

     jira issue attachment download ISSUE-KEY ATTACHMENT-ID [--output file]
     jira issue attachment download ISSUE-KEY --all [--output-dir dir]

     Flags:
     - --output, -o - Output file path
     - --output-dir, -d - Output directory (with --all)
     - --all - Download all attachments
     - --overwrite - Overwrite existing files

     3.5 Remove command

     jira issue attachment remove ATTACHMENT-ID [--force]

     Flags:
     - --force, -f - Skip confirmation prompt
